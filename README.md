# Mysteria: Lost Kingdom

Інтелектуальна навчальна RPG-гра з адаптивною системою навчання, AI-помічником та елементами гейміфікації.


## Про проєкт

Основною метоюмпроєкта було створення інтерактивної навчальної системи, яка поєднує механіки рольової гри, адаптивне навчання та технології штучного інтелекту. На відміну від традиційних навчальних платформ, користувач взаємодіє з відкритим ігровим світом, виконує квести, розв'язує навчальні завдання та поступово покращує характеристики персонажа. Складність завдань автоматично адаптується відповідно до успішності гравця.
